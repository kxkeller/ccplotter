Pen Calibration (plot + measure first)
Add whichever blocks you want to the page, then position and plot like any other job. Each uses the active pen's own resolved Z. Read: the loosest swatch still solid = fill spacing; the shortest strip row that inks = min stroke length; the tightest line pair still showing white = line width.

Coverage Debug (experimental · measurement only)
Compares SOURCE ink coverage vs what the current trace actually plots at your pen width. No strokes are generated — this is the review view before any coverage work.
Legend: ■ red = underfilled source ink (possible coverage target) · ■ blue = over-inked by pen width (leave alone) · neutral = roughly matched
Gap Audit (forensics · measurement only)
Tracks whether the white gaps in hatched shadows survive from the source file to the traced mask. Three stages: native res, after resample, after binarize. The stage where survival drops is the detail-killer. No strokes generated.

Z Heights & Speeds
Touch Z and Micro-lift are stored PER PEN and are what the server resolves at plot time. Set them with the fields above. The "Save Current Z as Touch Height" button below reads the printer's live Z over the network; it needs a printer host (CCPLOTTER_PRINTER_HOST) and cannot work on an offline plotter.
Travels under 8mm lift the pen to the Micro-lift height above instead of the full Pen Up height. Same Z-move count, a fraction of the Z travel — much less Z-axis lead-screw wear. Applied to the G-code only. If the pen draws faint lines BETWEEN marks, the micro-lift is not clearing the paper — raise it.
Motors release at the end of the plot. Next plot requires re-homing — remove the pen first.
