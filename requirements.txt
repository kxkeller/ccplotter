# ccPlotter runtime dependencies. Python 3.12 is required (the tests and the
# byte-identity golden hashes were produced on 3.12; other versions are untested).
# Use a python.org install, not the Microsoft Store build: the Store build
# virtualises %LOCALAPPDATA% and can serve stale copies of calibration files.
#
#   python -m venv .venv
#   .venv\Scripts\activate
#   pip install -r requirements.txt
#
# Exactly one OpenCV distribution is listed. The headless build is enough (the
# app uses no GUI/highgui calls), and OpenCV 5.0 matters: the two-tone mode's
# reference output hashes do not reproduce on OpenCV 4.x.
#
# `vpype-gcode` provides the `gwrite` command that writes all G-code.
# Optional extras (flow mode, OpenAI cleanup): requirements-optional.txt
# Running the tests: requirements-dev.txt
