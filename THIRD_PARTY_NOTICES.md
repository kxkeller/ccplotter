## `ccplotter/pfm_native.py` (Sketch Field)

This module reimplements the idea of a "greedy darkest-line search with brightness
erasure", as described in the public documentation prose of DrawingBotV3
(docs.drawingbotv3.com, the "Sketch Lines" pen-path-finding module). Its header
states that no DrawingBotV3 source code was read, fetched or consulted, and that
parameter names and ranges follow the documented parameter model. **No
DrawingBotV3 code is included in this repository.** DrawingBotV3 is an optional
external program, launched only if you set `CCPLOTTER_DBV3_EXE`; it is not
distributed here.
